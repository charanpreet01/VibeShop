# VibeShop

## Live Demo
[Live Demo](https://vibe-shop-frontend.vercel.app)

## Overview
VibeShop is a full-stack e-commerce platform built using the MERN stack. It allows users to browse, search, and purchase products seamlessly. The platform includes an admin panel for managing products, users, and orders, ensuring smooth operations.

## Features
- User authentication (Login/Signup)
- Add to cart functionality
- Sort and Product filtering by category
- Users can also track their orders
- Fully responsive design
- Secure API endpoints
- Admin panel to manage products, users, and orders

## Tech Stack
- **Frontend:** React.js, Context API, Tailwind CSS
- **Backend:** Node.js, Express.js
- **Database:** MongoDB
- **Authentication:** JWT (JSON Web Token)
- **Hosting:** Vercel (Frontend & Backend)
